# Data Structures in C++

This repository contains implementations and exercises on Data Structures and
Algorithms developed in C++, with a focus on fundamentals and the internal
workings of each structure.

## Objective

The project covers the implementation of major data structures and their
fundamental operations, exploring concepts such as:

- pointers and references;
- templates;
- dynamic memory allocation and deallocation;
- data structure invariants;
- time and space complexity analysis;
- implementation testing and validation;
- prevention of memory-related errors.

I also plan to solve practical problems involving these structures, such as

## Organization

The implementations are developed progressively, taking edge cases, tests,
invariants, and the time and space complexity of each operation into account.

The repository is updated as new concepts, data structures, and practical
problems are added to the project.
